# 算法用户镜像与每日练习设计

## 目标

在不改变既有答疑、渐进提示与最小修改的前提下，为每个确认用户维护独立算法镜像，并在每日 09:00（Asia/Shanghai）生成可完成的个人题单。

## 架构

答疑或打卡产生不可变学习事件；每日独立任务用事件日志与当前快照计算下一版画像和题单。数据放在 Google Drive `algorithm/users/<userId>/`，身份由 UUID 主键加用户名双重校验。未完成题优先续入，题单永远限制为 3～5 题。

## 一致性与失败

使用事件键幂等、快照版本乐观锁和历史快照。Drive 不能确认读写时停止本次执行，绝不输出或标记部分成功。

## 选题

满额题单为 1 道薄弱复习、2 道当前专题、2 道综合/变式；存在积压或前日完成不足时压缩为 3 题。候选范围为 Hot100、代码随想录、历史问题题与相关变式，七天内不重复同题。
