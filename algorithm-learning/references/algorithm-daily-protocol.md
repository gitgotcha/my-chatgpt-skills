# 每日算法练习

按 [RDS-JBryon 运行契约](../../references/rds-jbryon-runtime.md) 从 `knowledge/algorithm-learning/学习快照.json` 读取历史题目和进度。

1. 快照缺失、分页不完整或读取失败时说明未读取到完整历史，不编造掌握度。
2. 检查当日题单；已存在则原样使用，首次题单不可变。
3. 未完成题在下一日优先，明确卡点/错题优先，7 天内同题不重复；已推过但未完成的题作为继续练习提醒，不算新题。
4. 生成 3–5 道与已学范围相关的中文题；有实际掌握分时低分优先，同分选最久未复习；无分数不能编造分数。
5. 将题单追加到 JSON 快照；用户反馈后再追加学习记录，不覆盖原答或旧题单。
6. 输出题目、目标、角色和打卡格式，首次不泄露答案。

定时任务由用户自行管理。Skills 不读取其它用户目录，也不创建后台任务。
