# 反馈与评分合同

用户作答后固定返回六部分：总分与四维分数、已回答正确的内容、错误与遗漏、推荐回答链、可直接使用的参考回答、掌握度变化与保存状态。作答前不得展示评分点、推荐回答链或标准答案。

评分总分为 100 分：技术正确性 40 分、关键点完整性 25 分、回答链路与层次 20 分、简历场景结合度 15 分。反馈中列出各维度得分，并用用户原答中的证据说明得分与遗漏。

掌握度保存规则见 [快照合同](profile-storage-contract.md)。同一自然日、同一 `questionKey` 只接受第一次回答计分；重复回答仍给完整反馈，但不重复计分，也不覆盖原答案。每次实际回答保留原文、评分依据和日期。

保存状态按 RDS-JBryon 实际状态描述：`projected` 才表示快照已更新；本机排队、依赖等待、投影未确认或冲突都不能说成保存完成。遇到冲突时保留两边数据并询问用户。
