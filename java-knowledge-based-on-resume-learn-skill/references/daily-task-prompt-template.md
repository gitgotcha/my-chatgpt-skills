# 每日任务提示词模板

本模板只描述一次调用的提示词内容。定时任务由用户自行创建与管理，本技能不创建、不修改、不读取任何任务配置。

## 调用示例

用户在自己的任务配置中设定每天 09:00（Asia/Shanghai）执行：

```text
使用 java-knowledge-based-on-resume-learn-skill，
从 knowledge/java/resume-interview/学习快照.json 读取今天的简历八股练习历史。
```

自然日按 Asia/Shanghai 解释，不要求姓名或账户信息。

## 技能执行步骤

1. 通过 rds MCP 读取 knowledge/java/resume-interview/学习快照.json。
2. 检查已由用户确认的简历声明快照与题库；无简历时停止并提示用户提供简历。
3. 检查当日题单是否已存在。
4. 已存在则原样返回，不重新随机生成。
5. 不存在则按五题槽位选择题目，优先低分题，并追加保存到 JSON 快照。
6. 一次返回全部题面与来源标签，不返回答案、评分点或推荐回答链。

## 输出格式

今天的简历八股练习（<localDate>，时区 <timezone>，简历版本 <resumeVersion>）

1. [<知识点>] <题面>
   来源：简历明示 / 项目强推断；类型：原理题 / 场景题
2. ...

题单末尾说明选题依据：哪些来自低分复测、哪些是未考新题、证据不足时为什么少于五题。

## 边界

- 只返回题面，不提前暴露评分点与参考回答。
- 题单创建后当日不变，当天上传的新简历从下一个尚未创建题单的日期生效。
- 持久化只经 rds；只有查询状态显示 projected 才报告快照已保存。
