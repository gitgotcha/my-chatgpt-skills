# Device binding 发布候选手册

当前候选包默认保持 `selfRegister=false`、`adminInit=false`。账户注册与管理员初始化在完成审核门、备份验证和隔离 canary 前不公开。

发布顺序固定为：

1. 核对 M/S 两仓提交 SHA、运行时清单与 `packageHash`。
2. 对 D1、旧本机 Outbox 和设备控制库做可读、可恢复备份。
3. 在暗部署配置下验证 V2 路由，保持新账户开关关闭。
4. 运行 0008 迁移的双绑定测试；失败时回滚事务并保留旧备份。
5. 在独立测试账户和独立 Windows 登录用户下做配对、切换、重启和取消验证。
6. 安装候选包，确认 tools/list 只有 `submit_event`，再执行隔离 canary。
7. 获得独立审核与用户授权后，按阶段开启注册/配对限流；每次改动记录远端版本和回执。

回退只关闭新注册/配对开关并保留数据，不删除账户、凭据、Outbox 或 V2 事件，也不恢复按姓名的旧管理员入口。任何备份不可读、哈希不匹配、未知账户归属或缺少人工 Windows 隔离证据时，停止发布。

本手册不执行远程命令；命令必须显式指定 `wrangler.production.toml`，并在执行前再次取得授权。
