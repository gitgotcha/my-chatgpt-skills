# 姓名目录直连 Drive 设计

## 目标

只使用一个 Google Drive 根文件夹作为存储。调用方提供 `displayName` 后，系统直接在根目录中查找同名文件夹；同名即同一用户。

## 数据布局

```text
<Drive 根目录>/
  <displayName>/
    identity.json
    <面试产物、事件、简历等文件>
```

不使用候选人 ID、用户注册表、数据库、队列或异步同步。

## MCP 行为

`find_or_create_candidate` 接收 `displayName`。它先精确查找根目录下的同名文件夹；找到即返回该文件夹，找不到即创建同名文件夹与 `identity.json`，并在 Drive 返回文件 ID 后才返回。

所有读取和写入工具接收 `displayName`，内部先解析为该姓名目录。任何 Drive 读取、创建或写入失败都会作为 MCP 错误返回，不继续后续操作。

若根目录中已有多个同名文件夹，使用最早创建的文件夹作为该姓名的目录，以保持旧数据可访问；新调用不会再创建额外同名目录。

## 验证

测试覆盖：已有姓名复用目录、缺失姓名创建目录、创建或写入失败时停止、所有产物按姓名写入正确目录。
