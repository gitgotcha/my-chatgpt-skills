# 模拟面试题源比例设计

## 目标

让 Java 后端模拟面试更贴近真实面试：以简历和项目深挖为主，基础知识尽量绑定业务场景，同时保留历史弱点复测和算法/系统场景题。

## 题源配额

有简历或项目材料时，题目主来源采用互斥配额：

| 主来源 | 比例 |
| --- | ---: |
| 简历/项目 | 55% |
| 历史弱点变式 | 15% |
| 独立领域知识 | 10% |
| 算法与场景 | 20% |

主来源总和必须为 100%。领域知识和八股可以嵌入项目题或场景题，但通过 `topicTags` 标记，不重复计入主来源配额。

## 运行规则

- 题目数量不是 20 的倍数时，按最大余数法取整，优先保证项目题和算法/场景题的覆盖。
- 历史弱点变式不得复用原题；弱点复测不超过整场题数的 40%。
- 项目题可同时检查技术原理、架构取舍、故障处理和业务结果。
- 独立领域知识题只在无法自然嵌入项目或场景时使用。
- 无简历时继续使用无简历配额：历史弱点变式 35%、领域知识 45%、算法与场景 20%。

## 验收标准

模拟面试 Skill 必须明确记录上述有简历比例、主来源互斥计数、标签重叠规则和取整/弱点上限，契约测试必须锁定这些文字规则。
