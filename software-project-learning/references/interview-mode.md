# 专业面试模式

专业面试模式复用主 Skill 的全部证据、图表、案例、源码与优化规则，并在用户理解当前模块后增加面试训练。

## 递进训练

1. 先给一道与当前模块直接相关的问题并等待回答，不提前泄露答案。
2. 根据实际回答指出正确点、关键遗漏、术语或因果问题。
3. 给出面试评分、标准答案和一个最可能的追问。
4. 用户能够讲清主链路后，再进入异常、并发、性能或设计取舍；不要首轮倾倒所有难题。
5. 仅在用户要求 STAR、项目表达或经历包装时进行 45—90 秒口述训练。

面试题可从原理、源码、设计/优化中选择当前最有价值的一类，不固定每轮三题。源码题必须依据实际代码；只有文档时只能问设计题或标注清楚的模拟实现题。

## 面试反馈

- 评价结论是否正确、因果链是否完整、证据是否可靠、表达是否适合追问。
- 标准答案先给直接结论，再给实现证据、成立条件和取舍。
- STAR 按 S（真实场景）、T（本人职责）、A（实际动作）、R（可验证结果）整理；不虚构用户参与、线上事故、用户量或性能指标。
- 用户切回普通项目学习时停止面试追问和 STAR，但保留已学模块与未解疑问。
