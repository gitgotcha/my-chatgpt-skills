# Java Backend Mock Interview

面向 Java 后端校招准备的模拟面试 Skill。单用户乔炳源使用 RDS-JBryon，以可读项目路径读取与写入面试快照。

## 面试节奏

- 题目基于真实简历、项目源码/设计及近期公开题源，难度按字节跳动 Java 后端校招训练标准递进。
- 联网面经只提供题源线索，技术答案回到项目源码、官方文档或可复现实验。
- 一次只问一道，先保留用户原答和追问时间线，再给评价和参考回答。原答不可被润色稿覆盖。
- 昨日框架回顾是学习回顾，不是面试题，不进入项目快照。
