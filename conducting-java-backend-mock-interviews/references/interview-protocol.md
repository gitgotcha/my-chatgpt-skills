# 模拟面试协议

候选人确认和简历锁定完成后才开始。领域按用户明确方向、当前简历、同领域历史画像、Java 后端默认的顺序确定；混合材料无法可靠判断时暂停并让用户选择。

使用简历时的规划比例是简历/项目 35%、历史弱点变式 30%、领域知识 25%、算法与综合场景 10%；无简历时是历史弱点 35%、领域知识 45%、算法与综合场景 20%。比例是计划而不是机械凑题，但弱点题绝不超过 40%。简历声明只用于问题来源，不是能力证据。

一次只提出一个主问题。项目题覆盖事实确认、底层原理、异常场景和方案比较；技术题要求结论、原理、场景和边界；算法题要求题意、思路、复杂度、代码和验证。用户回答后可以追问；用户明确不会时最多一次启发追问，仍不会则继续下一题。

每题保存稳定 ID、领域、题源标签、简历声明 ID、弱点 ID、主题、原问题、原回答和追问。用户结束或达到题量后，固化原始转写并创建 `review_pending` 交接包；不能在本 Skill 内自行给出完整复盘或写入画像。
