# 模拟面试协议

本 Skill 面向乔炳源单用户，不做姓名身份解析。领域按用户明确方向、当前简历、所选项目的历史快照、Java 后端默认的顺序确定；混合材料无法可靠判断时暂停并让用户选择。

使用简历时的规划比例是简历/项目 55%、历史弱点变式 15%、领域知识 10%、算法与场景 20%；无简历时是历史弱点变式 35%、领域知识 45%、算法与场景 20%。比例是计划而不是机械凑题，但弱点题绝不超过 40%。简历声明只用于问题来源，不是能力证据。

项目专项（`project_targeted`）与完整 mock 并列：专项只从选中项目出题，允许一题必要的基础机制，不混其它项目弱点，也不参与 40% 弱点上限；完整 mock 的配额与 40% 上限不变。专项默认 L2 起步，按实际表现走向 L1 或 L3/L4；一次只问一道，作答前不泄露本题答案。选题与来源规则见 [项目专项面试](project-targeted-interview.md) 与 [联网题源与来源卡](web-question-sourcing.md)。

一次只提出一个主问题。以字节跳动校招 Java 后端训练难度为目标，但不声称内部题库或录用标准。项目题覆盖事实确认、底层原理、异常场景和方案比较；技术题要求结论、原理、场景和边界；算法题要求题意、思路、复杂度、代码和验证。用户回答后可以追问；用户明确不会时最多一次启发追问，仍不会则继续下一题。

每题保存稳定 ID、领域、题源卡、简历/项目源码锚点、主题、原问题、原回答和追问。用户结束或达到题量后，将原始作答与分开的评价追加到项目 `学习快照.json`；不得让参考答案覆盖用户原答。回顾昨天框架的问答不是本场 interview，不落入快照。
