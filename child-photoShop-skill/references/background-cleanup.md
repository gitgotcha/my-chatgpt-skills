# 背景清理与道具保护（Background Cleanup & Prop Protection）

背景清理是儿童摄影馆最高频的刚需。棚拍永远会有灯架、夹子、电线、背景布边缘入镜。

**但儿童写真的背景里混着主题道具。删错道具 = 毁掉整组主题。**

---

## 一、先做道具判定，再动手删

```text
Is this prop part of the theme?
  → 是 → preserve
  → 否 → 可以移除
```

### 通常属于主题、必须保留

```text
毛绒玩具      帐篷          气球          蛋糕
玩具望远镜    探险帽        地图          椅子
小汽车        积木          生日数字      彩带
主题背景布    手持道具      绘本          花环
```

### 通常属于杂物、可以移除

```text
摄影灯架      电线          夹子          背景布边缘/褶皱
垃圾          地面杂物      无关人员      纸张
明显污点      反光板边缘    引闪器        拖线板
摄影师的手/脚 器材包
```

### 灰色地带（需判断或询问）

- 工作人员的手（扶着孩子时）—— 通常移除，但如果手是互动的一部分则保留
- 家长的局部入镜 —— 亲子照中保留，单人照中移除
- 散落的道具 —— 主题相关则保留，杂乱无章则整理而非删除

**判定不清时，问用户一句话，不要自作主张删除。**

---

## 二、移除流程

```text
1. mask target       精确框定目标，mask 尽量贴合边缘，宁可略小不可过大
2. inpaint           修补背景
3. compare           与原图同位置并排对比
4. QA                伪影检查
```

**禁止重新生成整个照片。** 背景清理是局部操作，全图重生成必然带来身份漂移。

---

## 三、修补质量要求

修复后必须符合**原始场景逻辑**：

| 要求 | 说明 |
|---|---|
| 纹理连续 | 修补区域的纹理方向、尺度与周边一致 |
| 光照一致 | 修补区域的明暗与周边同一光源 |
| 透视正确 | 地板、墙面、背景布的透视不能错乱 |
| 无重复 | 不得出现重复的纹理图案（AI inpaint 的常见病） |
| 无半截物体 | 不得出现半个玩具、半张桌子 |

### 常见失败模式

```text
重复道具      扭曲帐篷      半个玩具
错误地板      不自然纹理    光晕/接缝
透视错乱      凭空生成的新物体
```

---

## 四、背景布与影棚边界

棚拍常见问题是背景布不够大，边缘、褶皱、接缝入镜。

- **边缘入镜**：inpaint 延展背景色，或轻微裁切（裁切需用户同意）。
- **褶皱**：轻微软化即可，**不要完全抹平** —— 完全抹平会显得背景是纯色塑料板，失去棚拍质感。
- **接缝**：inpaint 抹除，注意两侧亮度一致。

---

## 五、背景虚化与压暗

允许：轻微的背景降饱和、压暗、轻度虚化，用于突出主体。

禁止：

- 用"抠图 + 假模糊"制造廉价分离感（会出现主体边缘光晕）
- 把背景压成纯黑/纯白
- 背景压暗过度导致儿童像被"贴"上去的
- 删除全部背景细节（参考图风格要求背景"可识别主题"，只需轻微虚化）

参考图（露营主题）的做法是：**主体清晰，背景轻微虚化但仍可识别主题**。这个平衡点要保住。

---

## 六、QA 判定

| 检查项 | 失败表现 |
|---|---|
| 道具完整性 | 主题道具被删、被截断、被复制 |
| 纹理连续 | 出现重复纹理、糊块、不自然平滑区 |
| 光照一致 | 修补区与周边明暗/色温不一致 |
| 边缘质量 | mask 接缝、光晕、锯齿 |
| 主体安全 | 清理时误伤儿童身体、头发、服装 |
| 透视正确 | 地板/墙面透视错乱 |

任一失败 → 按 SKILL.md §十四 降级重试。
