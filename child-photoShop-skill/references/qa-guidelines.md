# QA 规范（Quality Assurance）

**每次生成式修改后必须 QA。传统调整后至少做影调与伪影检查。**

QA 不是走过场。AI 修图的失败往往很隐蔽：整体看着挺好，放大后发现孩子已经不是原来那个孩子了。

---

## 一、检查方法

1. **全尺寸 + 缩略图双看法**：全尺寸看伪影，缩略图看主体是否突出。
2. **原图并排对比**：不做对比就无法判断身份漂移。
3. **关键部位 100% 放大**：眼睛、嘴、手。
4. **批量任务做跨图比对**：把一组图拼成联系表一起看，一致性问题一眼可见。

---

## 二、Identity QA（身份）

比对项：

```text
face shape    eye shape    eye distance    nose
mouth         ears         hairline        expression
```

**Pass**：第一眼就能确认是同一个孩子。

| 常见失败 |
|---|
| 换了一个"更好看的通用儿童脸" |
| 脸型被收紧、下颌线变尖 |
| 眼睛变大或眼距改变 |
| 笑容被标准化（大笑 → 微笑） |
| 年龄感被抬高 |

有人脸比对后端时：嵌入余弦相似度 **≥ 0.90**。无后端时：逐项目视核对，任一项"不像"即 FAIL。

---

## 三、Childhood QA（童真）

检查：

```text
age appearance       年龄呈现
adult makeup         成人化妆痕迹
adult facial structure  成人面部结构
excessive contour    过度修容
```

**Pass**：看起来还是这个年龄的孩子。

| 常见失败 |
|---|
| 看起来比实际大 2 岁以上 |
| 出现眼影、唇妆、修容 |
| 面部软组织被收紧成成人轮廓 |
| 皮肤呈现与年龄不符的成熟质感 |
| 牙齿被补齐或美白成成人牙 |

---

## 四、Expression QA（表情）

检查：

```text
smile          笑容强度与形态
mouth open     嘴巴开合状态
gaze           眼神方向
eyebrows       眉毛状态
emotion        面部情绪
```

**Pass**：表情与原图一致，生动性未被削弱。

| 常见失败 |
|---|
| 张嘴变闭嘴 / 闭嘴变张嘴 |
| 大笑被削弱成微笑 |
| 眼神方向被改变 |
| 表情被标准化，失去生动性 |
| 凭空出现原图没有的酒窝、抬眉 |

---

## 五、Skin QA（皮肤）

检查：

```text
texture loss      纹理丢失
plastic skin      塑料感
color inconsistency  色块不一致
halo              光晕
excessive whitening  过度美白
```

**Pass**：皮肤干净、纹理真实、颜色均匀、年龄感正确。

| 常见失败 |
|---|
| 磨皮过度，毛孔纹理全失 |
| 塑料感、蜡像感、瓷娃娃感 |
| 脸颊与额头色块不一致 |
| 修复区域周围出现光晕 |
| 皮肤死白、失去血色 |
| 儿童被"美白"成成人肤色 |

---

## 六、Artifact QA（伪影）

检查：

```text
strange eyes        怪异眼睛
strange teeth       怪异牙齿
extra fingers       多指
hand deformation    手变形
clothing deformation  服装变形
duplicated toys     重复玩具
broken background   背景破损
strange hair        怪异头发
broken text         错乱文字
```

**Pass**：无任何 AI 生成伪影。

**手是重灾区**：生成式修复几乎必然在手指上出错。任何涉及手部的编辑都必须 100% 放大检查。

---

## 七、Theme QA（主题）

以 Camping Child 为例：

```text
帐篷是否完整      毛绒玩具是否正常
地图是否合理      色彩是否统一
背景是否符合露营主题
```

**Pass**：主题元素完整、色彩统一、道具不抢主体。

---

## 八、Batch Consistency QA（批量一致性）

跨图检查：

```text
same skin tone       同一肤色
same white balance   同一白平衡
same contrast        同一对比
same style           同一风格
same child identity  同一儿童身份
```

**Pass**：整组图看起来像同一个场次、同一套后期。

| 常见失败 |
|---|
| 第一张偏黄，第二张偏蓝，第三张过曝 |
| 同一孩子在不同图里肤色不一致 |
| 部分图套用了风格、部分图没套 |

实现方式：拼成联系表一起看，不要逐张单独检查。

---

## 九、判定与处置

```text
全部 PASS                → 交付
任一 FAIL                → 进入重试流程
重试后仍 FAIL            → 保留原图，说明失败原因
```

重试顺序（SKILL.md §十四）：

```text
1. 降低编辑强度
2. 缩小 mask
3. 切换后端
4. 回退到传统编辑
5. 仍失败 → 保留原图
```

**不得为了"完成交付"而输出错误结果。** 保留原图 + 说明失败原因是合法交付。

**不得原地重复同一参数重试。** 同一参数只会得到同一结果。

---

## 十、交付前的最低检查清单

- [ ] 与原图并排对比过
- [ ] 眼睛与嘴 100% 放大看过
- [ ] 手部（如涉及）100% 放大看过
- [ ] 主题道具完整、无重复、无扭曲
- [ ] 肤色真实、无塑料感、无过度美白
- [ ] 无高光剪切、无死黑
- [ ] 批量任务已做跨图一致性比对
- [ ] 原图未被覆盖
- [ ] `manifest.json` 已记录本次操作与 QA 状态
