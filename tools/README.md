# Tools

This repository contains the canonical local RDS-JBryon stdio MCP under [`rds-jbryon-mcp/`](./rds-jbryon-mcp/). It exposes the `rds` tool and stores durable local requests in the RDS-JBryon Outbox.

The MCP definition and path-based request contract are documented in the skill repository's [`references/rds-jbryon-runtime.md`](../references/rds-jbryon-runtime.md). Runtime implementation and deployment material live in the separate `my-chatgpt-mcp-v2` checkout.
