# 编辑模式

- `background-only`：仅编辑背景，人物整体保护。
- `skin-only`：仅做低强度肤色和自然血色调整，不改结构和肌理。
- `crop-only`：仅调整画布和裁切，不切断头发、头顶、手脚或关键道具。
- `theme-edit`：在背景和外围安全区域加入当前样本主题元素。
- `poster-edit`：在安全文字区加入可读文字与外围装饰。
- `batch-style-transfer`：冻结批次风格后逐图适配姿势、遮挡和留白。

坐姿元素置于身体两侧或前景边缘；躺姿围绕身体轮廓并保留呼吸空间；站姿维持脚底接触和人物比例；哭泣始终保留泪水、皱眉、张嘴等表达。留白不足时减少文字和装饰，不挤压人物。
