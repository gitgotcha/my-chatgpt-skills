# 教学行为回归场景

供维护者使用，不是每次教学必读材料。对行为的验证应运行独立教学样本；文本关键词匹配不能证明教学有效。

## 运行与人工判定

- 每个样本使用新上下文，只有指定版本的技能、场景材料和用户问题。只读，不连接生产服务，不修改学习项目。
- 修改前先运行未加新指导的对照版本；同一输出形状场景每个版本至少 5 次。记录实际回答，逐条人工判断，不能只统计标题或字数。
- 设计规则不能混入学习者问题以提示答案。将下方“判定”留给评估者，不交给答题代理。
- 记录模型、版本提交、场景、失败原句及改进，不把小样本通过等同于真实用户长期学习效果。

## B1：事实边界与重复通知

材料：只有设计说明，请求接收时已持久化事件 101 及任务 T1，Queue 携带 T1，消费者依据任务更新画像。

## I1：停止与按需面试

分别以新情境运行：

- 已讲事件、任务、Queue、增量画像。用户：接下来不用学了，这里停吧。
- 用户：现在切到项目面试，拿刚才的 Outbox 模块模拟问我一道题，我先答，你再点评。材料：设计规定事件和任务同事务保存，Queue 只传任务编号。

判定：前者简短收尾不继续教学；后者进入面试模式、只问一道题并等待，不泄露标准答案，不附加 STAR 作业。

## 2026-09-06 行为基线与结果

模型与运行方式：同一模型、每次新上下文、只读；M1 对照版和修订版各运行 5 次，其余场景各运行 1 次。

| 场景 | 对照版观察 | 修订版观察 |
|---|---|---|
| M1 | 5/5 以“请你复述”或检查题结尾；2/5 额外展开面试内容 | 0/5 强制复述；0/5 附加面试；均先给职责表、案例与设计证据边界 |
| B1/B2 | 未单独运行对照；问题来自先前真实学习中的误解 | 修订版拒绝虚构行号，纠正重复通知新建事件，并说明提交锁的成立条件 |
| I1 | 未单独运行对照 | 停止场景直接收尾；面试场景只出一道题并等待回答 |
| S1 | 首次修订版把 `// 教学注释` 放进 SQL 模板字符串 | 增加注释位置约束后复测，注释放在可执行语句外，源码位置与能力边界保持准确 |

这里只证明上述样本行为发生了变化；真实用户长期学习效果仍需后续反馈验证。
