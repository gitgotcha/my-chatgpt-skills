# 按需面试训练

仅在用户明确要求项目面试准备、源码问答或口述训练时读取。仍遵守主技能的图表、证据和只读边界。

- 围绕当前模块选择一个原理、源码或设计问题，而不是固定三类各出一题。
- 用户要模拟问答时先出题、等待回答，再指出关键错误、遗漏和可追问方向；用户要复习资料时直接提供题目与参考答案。
- 回答依据真实源码；尚未实现的设计只能作为设计讨论，不能写成个人完成的项目成果。
- 用户要求 STAR 或口述练习时，给一个 45–90 秒的练习目标。根据用户回答整理 S（场景）、T（职责）、A（实际动作）、R（可验证结果）；不虚构指标和经历。
- 用户回到业务理解时切回普通学习模式，不让面试模板持续占据后续回答。
