# 统一复盘协议

模拟和真实会话均使用同一 Review 结构。区别只在 `source_type`（`mock_interview` 或 `real_interview`）、`evidence_type`（系统转写、完整转写或候选人回忆）及 `evidence_confidence`。低可信候选人回忆不能与完整转写等权；清洗转写时只删除无意义口头语，歧义必须标记。

逐题记录原始问题、原回答、追问和追问回答、事后补充、考察意图、正确性、完整性、遗漏、错误、失分归因、更优口语回答、完整参考答案、表达分析和变式复测。逐题领域以实际问题内容为准；真实面试的算法问题按算法标准复盘，即使简历是 Java 后端。

复盘先固化原始会话，再校验 Review，生成 DOCX 并渲染检查，生成画像变化事件，在临时状态验证新画像，最后切换当前画像。模拟 Review 自动应用；真实 Review 默认生成 `pending` 预览，用户确认后应用，拒绝后保持 `rejected` 且不改变画像。云端不可用时标记 pending 状态，明确阻断，不得将临时文件冒充云端资料。
