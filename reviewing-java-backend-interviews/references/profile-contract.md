# 共享面试快照约定

模拟面试和复盘 Skill 共用乔炳源的 RDS-JBryon 单用户快照。数据按可读路径组织，面试题目、原答、追问、评价和复盘修订作为 JSON 内容保存在所选快照中。

## 快照原则

- `originalAnswer` 始终保存用户原始回答；讲评、参考答案和建议放在独立字段。
- 修订保留原记录并追加版本，不覆盖历史回答或评价。
- 只记录当前会话可核实的事实、明确评价和已发生的学习行为。
- 本地 JSON/DOCX 是本地输出，不能冒充云端快照。
- 路径选择、读写、状态和冲突处理遵守 [`../../references/rds-jbryon-runtime.md`](../../references/rds-jbryon-runtime.md)。

Python 领域函数只负责输入校验、评分与报告组装，不执行云端投影或模拟远端持久化。
